# ABPM CRF

แบบบันทึกข้อมูลตาม CRF ABPM ทั้ง 5 ส่วน สร้าง Excel .xlsx ในเครื่อง ไม่มี backend, analytics, external dependencies หรือการบันทึกลง localStorage / IndexedDB / cookies

## เปิดใช้งานในเครื่อง

เปิด index.html ด้วย Chrome หรือ Edge ได้โดยตรง ไม่ต้องติดตั้งโปรแกรมและไม่ต้องใช้อินเทอร์เน็ต กรอกข้อมูลจำลองเพื่อตรวจสอบก่อนใช้งานจริง

1. กรอกหนึ่งราย ใช้รหัสวิจัยแทนชื่อหรือ HN
2. กดเสร็จสิ้นและดาวน์โหลด Excel เบราว์เซอร์อาจถามตำแหน่งบันทึก
3. เปิดตรวจไฟล์ที่ได้ ข้อมูลอยู่ในชีต Data หนึ่งแถว พร้อม Codebook และ Readme
4. กดล้างข้อมูล / เริ่มรายใหม่

แต่ละครั้งจะได้ไฟล์แยกกัน ไม่สะสมต่อในไฟล์เดิม ข้อมูลไม่ถูกล้างอัตโนมัติหลังสั่งดาวน์โหลด เพราะหน้าเว็บไม่สามารถยืนยันการเขียนไฟล์สำเร็จ

## ขึ้น GitHub Pages

1. ไป https://github.com/new เลือกเจ้าของ aphiaut และชื่อ repository abpm-crf
2. เลือก Public (โค้ดและแบบฟอร์มเปล่าเผยแพร่สาธารณะ ห้ามอัปโหลดข้อมูลจริง) แล้ว Create repository
3. เลือก uploading an existing file อัปโหลด index.html และ README.md จากโฟลเดอร์นี้ แล้ว Commit changes
4. Settings → Pages → Source: Deploy from a branch → main → /(root) → Save
5. รอ GitHub แสดง URL เว็บไซต์ในหน้า Pages แล้วเปิดทดสอบ

อ้างอิง https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## ขอบเขตความเป็นส่วนตัว

- CSP ปิด network connections, form submissions และการโหลดทรัพยากรภายนอก
- ข้อมูลแบบฟอร์มอยู่ใน DOM/หน่วยความจำระหว่างกรอก ไม่มีการส่งผ่าน URL หรือ API
- เว็บไม่รับรองการลบหน่วยความจำแบบกู้คืนไม่ได้ หรือควบคุมส่วนขยาย การจำข้อมูลของเบราว์เซอร์ ระบบ sync และการสำรองไฟล์ของเครื่อง
- GitHub Pages อาจมีบันทึกการเข้าถึงหน้าเว็บ เช่น IP แต่แอปไม่ส่งข้อมูลแบบฟอร์มให้ผู้ให้บริการ
- หากต้องการลดการเชื่อมต่อเครือข่าย ให้ใช้ index.html แบบออฟไลน์
- เลือกตำแหน่งดาวน์โหลดที่ไม่ sync ออนไลน์ หากต้องการเก็บไฟล์เฉพาะเครื่อง

## ข้อมูลและการตรวจสอบ

59 ตัวแปร ค่าว่างหมายถึงไม่ได้บันทึก ตัวเลขเป็นตัวเลข วันที่เป็นข้อความ YYYY-MM-DD ค.ศ. หมวดหมู่เป็นรหัสตาม Codebook
ตัวเลือกหลายข้อแยกคอลัมน์ โดยแต่ละข้อเลือก 1=มี/เลือก, 0=ไม่มี/ไม่เลือก หรือว่าง=ไม่ได้บันทึก เพื่อแยกข้อมูลขาดหายจากคำตอบไม่มี

ส่วนที่ 4 คัดลอกผลจาก comment ไม่มีการวินิจฉัยจากตัวเลข ชื่อเรื่องปรับถ้อยคำพิมพ์ผิดเป็นแบบพยาบาลเป็นผู้นำ
BP load ในต้นฉบับระบุ ≥135/85 ทั้งกลางวันและกลางคืน เว็บเก็บค่าที่คัดลอกจากรายงาน ไม่เปลี่ยนเกณฑ์
ตรวจความสอดคล้อง Successful และ Dip เมื่อกรอกทั้งตัวเลขและหมวด โดยไม่เติมหมวดให้อัตโนมัติ
มีเพียงรหัสวิจัยที่บังคับกรอก ช่องอื่นเว้นว่างได้ตามข้อมูลย้อนหลัง

## ผลตรวจทางเทคนิค

ตรวจไวยากรณ์ JavaScript และทดสอบสร้างไฟล์เปิดด้วย openpyxl: ผ่าน ตรวจ 59 คอลัมน์ไม่ซ้ำ ค่าไทย ตัวเลข ค่าว่าง และข้อความขึ้นต้น = ถูกเก็บเป็นข้อความ
ยังไม่ได้ทดสอบการคลิกดาวน์โหลดจริงในเบราว์เซอร์หรือการเผยแพร่ GitHub Pages กรุณาทดสอบด้วยข้อมูลจำลองก่อนใช้จริง
