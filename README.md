คู่มือทดลองเว็บ ABPM — ฉบับแยกไฟล์

1. คลิกขวา ZIP แล้วเลือก Extract All / แยกทั้งหมด
2. เปิด index.html ด้วย Chrome หรือ Edge (ไม่ต้องติดตั้ง Python)
3. ทดลองกรอกข้อมูลสมมติ กดดาวน์โหลด Excel แล้วเปิดตรวจ
4. เมื่อตรวจไฟล์แล้วกดล้างข้อมูลเพื่อเริ่มรายใหม่
เก็บทุกไฟล์ในโฟลเดอร์เดียวกัน เปิดจาก ZIP โดยตรงไม่ได้

แก้สี: คลิกขวา style.css > Open with > Notepad หรือ VS Code
แก้ค่าในช่วง :root ด้านบน เช่น
--primary: #176653;     สีปุ่มและลิงก์
--header-bg: #123e3b;   สีส่วนหัว
--page-bg: #f3f7f6;     สีพื้นหลัง
--card-bg: #ffffff;     สีพื้นการ์ดและช่องกรอก
--text-color: #183a3a;  สีข้อความหลัก
--font-size: 16px;     ขนาดตัวอักษรหลัก
ตัวอย่างสีม่วง: เปลี่ยน --primary เป็น #7C3AED และ --header-bg เป็น #4C1D95
กด Ctrl+S แล้วกลับหน้าเว็บกด Ctrl+R (ข้อมูลที่กำลังกรอกจะหาย ควรดาวน์โหลดก่อน)

แก้คำถาม: เปิด questions.js ค้นคำด้วย Ctrl+F แล้วแก้ข้อความที่อยู่ในเครื่องหมายคำพูด
ตัวอย่าง 'รหัสวิจัย' เปลี่ยนเป็น 'รหัสผู้เข้าร่วมวิจัย'
อย่าลบเครื่องหมายคำพูด จุลภาค หรือวงเล็บ อย่าเปลี่ยน study_id และรหัสตัวแปรอื่น
อย่าเปลี่ยนรหัสคำตอบ เช่น '0', '1' หากยังต้องการใช้ข้อมูลกับ codebook เดิม
เพิ่ม/ลบช่องหรือเปลี่ยนรหัสคำตอบจะกระทบโครงสร้าง Excel ต้องตรวจร่วมกับนักสถิติ
ชื่อหน้าเว็บ คำเกริ่น ปุ่ม และข้อความท้ายเว็บแก้ใน index.html
app.js คือส่วนปุ่ม ตรวจข้อมูล และสร้าง Excel ปกติไม่ต้องแก้
สำรองโฟลเดอร์ก่อนปรับแต่งทุกครั้ง

กรอก 1 ราย ดาวน์โหลด 1 ครั้ง ได้ .xlsx 1 ไฟล์ มี Data, Codebook และ Readme
โปรแกรมไม่มี backend, analytics, cookies, localStorage หรือการเรียก API
ไม่ต้องเชื่อมต่ออินเทอร์เน็ตสำหรับการกรอกและสร้าง Excel
ข้อมูลอยู่ในหน่วยความจำระหว่างกรอก ไม่รับรองการล้างหน่วยความจำแบบกู้คืนไม่ได้
เลือกโฟลเดอร์ดาวน์โหลดที่ไม่ sync ออนไลน์หากต้องการเก็บเฉพาะเครื่อง

ฉบับนี้แยกไฟล์สำหรับใช้ทั้งในเครื่องและ GitHub Pages
เมื่อต้องการใช้บน GitHub Pages ต้องอัปโหลด index.html, style.css, questions.js, app.js พร้อมกัน
